## Featured Projects

**Mela-Money**
Live production RAG app at melamoney.com helping Black women founders find SBA grants, WOSB, MBE, 8(a) and federal funding. Built on AWS Bedrock Knowledge Bases with Claude 3 Haiku, OpenSearch Serverless, Lambda, API Gateway, DynamoDB and CloudFront. Full infrastructure as code with CloudFormation.

**Mela-Mindful**
Capstone GenAI project. Progressive Web App for weekly accountability and affirmations. Consolidates Bedrock foundations, RAG and guardrails patterns into one product. Phone-first design with a grounded mentor voice.

**Bedrock Starter Kit**
Reference implementation for calling Amazon Bedrock foundation models with Python and Boto3. Covers model invocation, prompt patterns and basic guardrails. Built as a study companion for the AIP-C01 exam.

**RAG Mini Lab**
End-to-end retrieval-augmented generation pipeline on AWS. Ingests documents into a Knowledge Base, indexes with OpenSearch Serverless and serves answers through Lambda and API Gateway. Maps to the AIP-C01 retrieval and grounding domain.

**DevOps Home Lab on Apple Silicon**
ARM-compatible home lab built with Vagrant, VMware Fusion and Docker on an M4 MacBook Air. Full five-tier stack running Nginx, Tomcat, MariaDB, Memcached and RabbitMQ. Built to simulate production infrastructure locally.
